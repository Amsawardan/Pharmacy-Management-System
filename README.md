# Pharmarcy-Managment-System

##  Project Overview
This project is a Pharmacy Management System designed to streamline and manage daily pharmacy operations efficiently. It provides functionalities for handling User, order, inventory, and Admin Dashboard management through a structured and user-friendly system.

## Demo Video
Watch the full project demonstration here:

## 🛠️ Technologies Used
- Programming Language: java
- Concepts: File Handling, CRUD Operations

## 🧩 System Functionalities
- Add new medicines to the system
- Update existing medicine details
- Delete medicine records
- Generate bills for customers
- Maintain stock and inventory levels
